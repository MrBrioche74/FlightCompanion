# Flight Companion v0.2

Version de test SimConnect pour Microsoft Flight Simulator 2024.

## Données automatiques
- altitude indiquée ;
- vitesse sol ;
- vitesse verticale ;
- cap vrai ;
- avion.

## Installation
1. Copie `Microsoft.FlightSimulator.SimConnect.dll` dans `FlightCompanion/lib/`.
2. Double-clique sur `build-exe.bat`.
3. Lance MSFS 2024 et entre dans un vol.
4. Lance `Flight Companion v0.2.exe`.

La DLL est volontairement exclue du dépôt public.
